1. Package `backend/src/mnemonic/search/` — NO imports of fastapi/psycopg/settings. Generic `doc_id: str` (later = chunk id).
2. `tokenizer.py`: NFKC + casefold, tokens by unicode `\w+`. **Code-aware**: for `response_model`, `OAuth2PasswordBearer`, `fastapi.security` also emit the parts (split on `_`, camelCase boundaries, digits kept with letters) at the SAME position as the whole token.    `stopwords.py`: ~100 English stop words. Stop words are dropped from the index/query but **positions still advance**.
3. `index.py` — `InvertedIndex`: `add_document(doc_id, text)` (re-adding replaces), `remove_document(doc_id)`, `postings(term)`, `df(term)`, `N`, `avgdl`, doc lengths. Positional postings: `term → {internal_doc_idx → list[int]}`. `save(path)` / `load(path)` as JSON with a `version` field (reject unknown version), atomic write (temp file + `os.replace`).
4. `ranking.py`: `tf_idf` (`tf * log(N/df)`, 0 for terms in every doc — documented) and `bm25` (k1=1.5, b=0.75, idf = `log(1 + (N - df + 0.5)/(df + 0.5))`, never negative). Both return **per-term contributions** per doc (needed by explain). Put the exact formulas in the docstring.
5. `query.py`: parse `foo bar` (all terms), `"exact phrase"`, `-word` (exclude). `engine.py` — `SearchEngine.search(query, *, mode="all"|"any", limit=10, allowed_ids=None, ranker="bm25") -> list[Hit(doc_id, score, snippet, matched_terms)]`. `all` = AND (brief Standard); `any` = union, ranked (used by RAG in M2). Phrase = consecutive positions via positional intersection. `allowed_ids` filters before ranking. `explain(query, doc_id)` → per term: tf, df, idf, doc length, contribution; the contributions sum to the score.
6. `snippets.py`: ~160-char window around the densest match region, snapped to word boundaries (never cuts a word), returns `Snippet(text, highlights=[(start, end), ...])` — offsets into `text`, never HTML.
7. `backend/scripts/search_cli.py`: `--dir` (default: the FastAPI docs corpus used by ingest; if not found, ask via an error message), interactive loop printing rank, score, doc id, snippet with `**` marks and the latency in ms; `--bench`: index time, docs, unique terms, index size in MB (JSON), and p50/p95 query latency over ~20 fixed queries (include one-word identifiers like `Depends`, `CORS`, multi-word, and a phrase). Robustness: missing folder → clean message; empty file → skipped with a count; non-UTF-8 → `errors="replace"` with a count. Also: `--ranker tfidf|bm25`, `--mode all|any`, `--explain N` (explain the Nth hit).
