## Scope
Every data endpoint is scoped to the user from the Bearer token. `X-API-Key`, `APP_API_KEY`, `owner_id` disappear from the API. Sessions become a server-side CRUD resource.

## Tasks
1. **Migration `0003_ownership`** (raw SQL, with a docstring warning that it DELETES legacy anonymous data):
   - `DELETE FROM documents` (chunks go by cascade), `DELETE FROM chunks WHERE owner_id IS NOT NULL`, `DELETE FROM sessions` (messages and llm_calls cascade). Shared FastAPI-docs chunks (owner_id NULL) stay.
   - `sessions`: add `user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `title text NOT NULL DEFAULT 'New chat'`, `updated_at timestamptz NOT NULL DEFAULT now()`; index `(user_id, updated_at DESC)`.
   - `documents.owner_id` and `chunks.owner_id`: add FK to `users(id) ON DELETE CASCADE`.
   - Downgrade drops the FKs and the new columns (deleted data is not restored: say so in the docstring).
2. **Auth swap**: remove `require_api_key`, `app_api_key` (config, lifespan check, `.env.example`) and every `owner_id` field/param (`ChatRequest`, `FlashcardRequest`, `/documents`, `/chunks`). Protected routes use `Depends(get_current_user)` FIRST, then `limit_per_ip` (unauthenticated requests must never touch the limiters). The user id passed to the store / retriever is `user.id`. `get_current_user` also stores the user id in `request.state.user_id` (for the logs).
3. **Sessions resource** (new `routes_sessions.py`, `APIRouter(prefix="/sessions", tags=["sessions"])`):
   - `POST /sessions` `{title?}` → 201 `{id, title, created_at, updated_at}`; the id is generated by the server.
   - `GET /sessions?limit=20&offset=0` → `{items, total, limit, offset, next}` where `next` is the next offset or null; `limit` 1..100, `offset` ≥ 0, otherwise 422. Newest `updated_at` first.
   - `GET /sessions/{id}`, `PATCH /sessions/{id}` `{title}` (1..100 chars), `DELETE /sessions/{id}` → 204 (cascade).
   - `GET /sessions/{id}/messages` stays, but now: not the caller's or unknown → **404** (was: empty list).
   - `/chat` and `/flashcards`: the session must belong to the caller, otherwise 404 (no more implicit session creation in `add_message`). Each saved message bumps `updated_at`; when the title is still the default, the first user message sets it to its first 60 characters.
   - Ownership is enforced in SQL (`WHERE id = %s AND user_id = %s`), never "fetch then compare in Python". Someone else's id and a missing id give the same 404.
4. **Account**: `DELETE /auth/me` → 204 (cascades sessions, documents, chunks). `GET /health` → `{"status": "ok"}` (no auth, no DB: liveness only), tag `system`.
5. **JSON request logs**: one middleware, one JSON line per request on logger `mnemonic.access`: `ts, method, path` (route template when matched, e.g. `/sessions/{session_id}`), `status, duration_ms, user_id` (or null), `ip`. NEVER log headers, query strings, bodies or tokens. For streaming `/chat` the duration is time to response start: note it in a comment.
